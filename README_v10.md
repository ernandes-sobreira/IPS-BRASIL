# IPS Brasil v10

Correção específica da busca global de indicadores.

## Corrigido

- clicar em um resultado da busca agora seleciona o indicador corretamente;
- a lista fecha após a seleção;
- a plataforma volta para a aba Mapa;
- o mapa e a legenda são atualizados;
- o indicador escolhido fica destacado e é trazido para a área visível da lista;
- navegação por teclado (setas e Enter) permanece funcionando.

## Dados

Os três arquivos de dados foram copiados sem alteração da v9.
